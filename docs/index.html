Architecture

Native WPF, no browser wrapper.

Browser-based desktop apps wrap a full Chromium runtime just to draw text, burning 300–500 MB of memory in the background. LyricalWidget is a native .NET 10 WPF app, so there is no browser to run next to your game.

Playback timing comes straight from Windows SMTC. Lyrics are requested from LRCLIB and NetEase in parallel and cached for 30 days. Updates come from GitHub Releases.

Transparency

Privacy & Terms

No Telemetry, No Tracking

LyricalWidget has no telemetry or analytics and never tracks or sells your data. Song detection stays on your PC through Windows SMTC.

Network Requests

The only outbound requests are lyric and artwork lookups (LRCLIB, NetEase, iTunes/Deezer) and GitHub Release checks. The full source is on GitHub if you want to check.
