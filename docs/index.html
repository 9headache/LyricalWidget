Architecture

Native speed, zero wrapper tax.

Browser-based desktop apps wrap a full Chromium runtime just to draw text, burning 300–500 MB of memory in the background. LyricalWidget compiles natively on .NET 10 WPF so it stays invisible to your frame counter.

Playback hooks directly into Windows SMTC with millisecond timing, races LRCLIB and NetEase in parallel with 30-day offline lyric caching, and checks GitHub Releases automatically in place.

Transparency

Privacy & Terms

Zero Telemetry. Zero Tracking.

LyricalWidget collects zero telemetry, zero analytics, and never tracks or sells your data. Song detection stays 100% local via Windows SMTC.

Open-Source Network Lookups

Outbound requests are strictly lyric and artwork fetches (LRCLIB, NetEase, iTunes/Deezer) and GitHub Release checks. The entire codebase is open source: feel free to inspect every line on GitHub.
