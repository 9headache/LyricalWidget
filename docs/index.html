Features & Modes

Procedurally formats song lyrics into syntax-highlighted code with an authentic multiplayer artist cursor, syntax tokens, and smooth macro camera tracking.

Quickstart

Get started in minutes

No complex configuration or setup wizards. Run the executable and it connects automatically to your running media players.

1

Download LyricalWidget.exe

Single portable executable. Place it anywhere on your drive—no installation or admin rights required.

2

Play anything on Spotify

Works seamlessly with Spotify, Apple Music, Tidal, or browser media sessions via native Windows SMTC.

3

Press Alt + F for Fullscreen

Instantly launch cinema-grade kinetic typography, or keep the compact floating widget docked anywhere.

shortcuts.conf
Alt + F Toggle Fullscreen Kinetic Mode
Alt + V Cycle Kinetic typography vibe
Alt + L Toggle click-through lock
Ctrl + Wheel Volume control on album art
